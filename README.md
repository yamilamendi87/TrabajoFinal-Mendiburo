# Trabajo Final - Automatización de Pruebas (QA Automation)

Proyecto final desarrollado para la Diplomatura en Testing Profesional, enfocado en la automatización de pruebas funcionales y validación de flujos web.

## Tecnologías y herramientas
- **Lenguaje:** Java
- **Framework de automatización:** Selenium WebDriver
- **Runner y aserciones:** TestNG
- **Gestión de dependencias:** Maven
- **IDE:** IntelliJ IDEA

## Estructura del proyecto
- `src/test/java`: Clases de prueba automatizadas y casos de test.
- `pom.xml`: Configuración de Maven y dependencias del proyecto.

## Requisitos previos
- Tener instalado **Java JDK** (versión 11 o superior).
- Tener instalado **Maven**.
- Navegador **Google Chrome** actualizado.
